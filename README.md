# Placement Prediction App 🚀

**Live Demo:** https://placement-app-lirhdkds2j9xcq2lorqcn3.streamlit.app

An ML-based application that predicts student placement based on CGPA and IQ score.

### Features
- Predicts placement probability
- Interactive UI built with Streamlit
- Includes both Python and C++ implementations

### Files
- `app.py` - Main Streamlit application (Python)
- `placement.cpp` - Logic implementation in C++
- `model.pkl` - Trained Machine Learning model
- `requirements.txt` - Dependencies

### How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
